# Save One Person

Landing page for [Save One Person](https://save-one-person.vercel.app/) — a nonprofit using media to raise organ donation awareness and save lives.

## Live Site

[https://save-one-person.vercel.app/](https://save-one-person.vercel.app/)

## Structure

- `save-one-person.html` — Single-file HTML/CSS/JS landing page
- `vercel.json` — Vercel deployment config

## Deployment

The site is deployed on [Vercel](https://vercel.com). Any push to `master` can be redeployed with:

```bash
vercel --prod --yes
```
